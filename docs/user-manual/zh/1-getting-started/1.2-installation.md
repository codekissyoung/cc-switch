# 1.2 安装指南

## 官方渠道与系统要求

请只从 **ICodeEasy 官方下载页 [icodeeasy.cc/download/](https://icodeeasy.cc/download/)** 获取安装包。下载入口始终位于 icodeeasy.cc，安装包由短期签名链接提供；每个安装包都公布文件大小和 SHA-256，下载后可自行校验完整性。

| 系统    | 最低版本                   | 架构                                      |
| ------- | -------------------------- | ----------------------------------------- |
| Windows | Windows 10 及以上          | x64 / ARM64                               |
| macOS   | macOS 12 (Monterey) 及以上 | 通用包（Intel x64 / Apple Silicon arm64） |
| Linux   | 见下方发行版说明           | x64 / ARM64                               |

## 前置要求

### 安装 Node.js

ICodeEasy 管理的 CLI 工具（Claude Code、Codex、Gemini CLI）需要 Node.js 环境。

**推荐版本**：Node.js 18 LTS 或更高版本

#### Windows

1. 访问 [Node.js 官网](https://nodejs.org/)

2. 下载 LTS 版本安装包

3. 运行安装程序，按提示完成安装

4. 验证安装：

```bash
node --version
npm --version
```

#### macOS

```bash
# 使用 Homebrew 安装
brew install node

# 或使用 nvm（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# 或使用 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### 安装 CLI 工具

也可以在「设置 → 关于」中使用内置的托管安装/升级功能，或按以下方式手动安装。

#### Claude Code

**方式一：Homebrew（macOS 推荐）**

```bash
brew install claude-code
```

**方式二：npm**

```bash
npm install -g @anthropic-ai/claude-code

# 国内用户如下载慢，使用镜像源
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

#### Codex

**方式一：Homebrew（macOS 推荐）**

```bash
brew install codex
```

**方式二：npm**

```bash
npm install -g @openai/codex

# 国内用户如下载慢，使用镜像源
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

#### Gemini CLI

**方式一：Homebrew（macOS 推荐）**

```bash
brew install gemini-cli
```

**方式二：npm**

```bash
npm install -g @google/gemini-cli

# 国内用户如下载慢，使用镜像源
npm install -g @google/gemini-cli --registry=https://registry.npmmirror.com
```

> 💡 **提示**：如果经常遇到下载慢的问题，可以全局设置镜像源：
>
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## Windows

### 安装包方式

1. 在[官方下载页](https://icodeeasy.cc/download/)下载 `ICodeEasy-v{版本号}-Windows.msi`（ARM64 设备选择 `ICodeEasy-v{版本号}-Windows-arm64.msi`）
2. 双击运行安装程序
3. 按提示完成安装

注意：运行安装程序后如果没有任何反应，可以在文件上点击右键，在弹出的菜单中打开 `属性`，`常规`页中的 `安全` 勾选 `解除锁定`

### 绿色版（免安装）

1. 下载 `ICodeEasy-v{版本号}-Windows-Portable.zip`（ARM64 设备选择 `ICodeEasy-v{版本号}-Windows-arm64-Portable.zip`）
2. 解压到任意目录
3. 运行其中的 ICodeEasy 主程序

## macOS

1. 下载 `ICodeEasy-v{版本号}-macOS.dmg`（通用包，同时支持 Intel 与 Apple Silicon；也可选择 `ICodeEasy-v{版本号}-macOS.zip`）
2. 打开 DMG（或解压 zip）得到 `ICodeEasy.app`
3. 拖动到「应用程序」文件夹

正式安装包已经过 Apple Developer ID 签名和公证，可直接安装打开，无需额外操作。

## Linux

### Debian / Ubuntu（.deb）

1. 根据架构下载 `ICodeEasy-v{版本号}-Linux-x86_64.deb` 或 `ICodeEasy-v{版本号}-Linux-arm64.deb`
2. 安装：

```bash
sudo dpkg -i ICodeEasy-v{版本号}-Linux-*.deb

# 如果有依赖问题
sudo apt-get install -f
```

### Fedora / RHEL（.rpm）

1. 根据架构下载 `ICodeEasy-v{版本号}-Linux-x86_64.rpm` 或 `ICodeEasy-v{版本号}-Linux-arm64.rpm`
2. 安装：

```bash
sudo dnf install ./ICodeEasy-v{版本号}-Linux-*.rpm
```

### AppImage（通用）

1. 根据架构下载 `ICodeEasy-v{版本号}-Linux-x86_64.AppImage` 或 `ICodeEasy-v{版本号}-Linux-arm64.AppImage`
2. 添加执行权限：

```bash
chmod +x ICodeEasy-v{版本号}-Linux-*.AppImage
```

3. 运行：

```bash
./ICodeEasy-v{版本号}-Linux-*.AppImage
```

## 验证安装

安装完成后，启动 ICodeEasy：

1. 应用窗口正常显示
2. 系统托盘出现 ICodeEasy 图标
3. 应用切换器中能看到已启用的受管应用，并能切换到目标应用面板

## 版本更新

ICodeEasy 不包含自动更新，采用「轻量版本检查 + 官网手动下载」的方式升级：

- 「设置 → 关于」页会自动检查当前是否为最新版本，发现新版本时显示提示
- 点击检查更新即可打开官方下载页
- 下载最新安装包覆盖安装即可，配置数据不受影响

## 卸载

### Windows

- 通过「设置 → 应用」卸载
- 或运行安装目录下的卸载程序

### macOS

- 将 `ICodeEasy.app` 移到废纸篓
- 可选：删除配置目录 `~/.icodeeasy/`（以及仍保留的旧版回退副本 `~/.cc-switch/`，如存在）

### Linux

```bash
# Debian/Ubuntu
sudo apt remove icodeeasy

# Fedora/RHEL
sudo dnf remove icodeeasy

# AppImage：直接删除 .AppImage 文件即可
```
