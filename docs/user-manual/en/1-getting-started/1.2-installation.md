# 1.2 Installation Guide

## Official Channels and System Requirements

Only download ICodeEasy from the **official download page at [icodeeasy.cc/download/](https://icodeeasy.cc/download/)**. Downloads are always served from icodeeasy.cc via short-lived signed links; every installer publishes its file size and SHA-256 so you can verify integrity after downloading.

| System  | Minimum Version              | Architecture                                      |
| ------- | ---------------------------- | ------------------------------------------------- |
| Windows | Windows 10 or later          | x64 / ARM64                                       |
| macOS   | macOS 12 (Monterey) or later | Universal build (Intel x64 / Apple Silicon arm64) |
| Linux   | See distribution notes below | x64 / ARM64                                       |

## Prerequisites

### Install Node.js

The CLI tools managed by ICodeEasy (Claude Code, Codex, Gemini CLI) require a Node.js environment.

**Recommended version**: Node.js 18 LTS or higher

#### Windows

1. Visit the [Node.js official website](https://nodejs.org/)

2. Download the LTS version installer

3. Run the installer and follow the prompts

4. Verify installation:

```bash
node --version
npm --version
```

#### macOS

```bash
# Install with Homebrew
brew install node

# Or use nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Or use nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### Install CLI Tools

You can also use the built-in managed install/upgrade feature in "Settings > About", or install manually as follows.

#### Claude Code

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install claude-code
```

**Option 2: npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install codex
```

**Option 2: npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install gemini-cli
```

**Option 2: npm**

```bash
npm install -g @google/gemini-cli
```

## Windows

### Installer

1. Download `ICodeEasy-v{version}-Windows.msi` from the [official download page](https://icodeeasy.cc/download/) (on ARM64 devices, choose `ICodeEasy-v{version}-Windows-arm64.msi`)
2. Double-click to run the installer
3. Follow the prompts to complete installation

### Portable Version (No Installation Required)

1. Download `ICodeEasy-v{version}-Windows-Portable.zip` (on ARM64 devices, choose `ICodeEasy-v{version}-Windows-arm64-Portable.zip`)
2. Extract to any directory
3. Run the ICodeEasy executable inside

## macOS

1. Download `ICodeEasy-v{version}-macOS.dmg` (universal build for both Intel and Apple Silicon; `ICodeEasy-v{version}-macOS.zip` is also available)
2. Open the DMG (or extract the zip) to get `ICodeEasy.app`
3. Drag it to the Applications folder

Official releases are signed with an Apple Developer ID and notarized, so you can install and open the app directly — no extra steps needed.

## Linux

### Debian / Ubuntu (.deb)

1. Download `ICodeEasy-v{version}-Linux-x86_64.deb` or `ICodeEasy-v{version}-Linux-arm64.deb` for your architecture
2. Install:

```bash
sudo dpkg -i ICodeEasy-v{version}-Linux-*.deb

# If there are dependency issues
sudo apt-get install -f
```

### Fedora / RHEL (.rpm)

1. Download `ICodeEasy-v{version}-Linux-x86_64.rpm` or `ICodeEasy-v{version}-Linux-arm64.rpm` for your architecture
2. Install:

```bash
sudo dnf install ./ICodeEasy-v{version}-Linux-*.rpm
```

### AppImage (Universal)

1. Download `ICodeEasy-v{version}-Linux-x86_64.AppImage` or `ICodeEasy-v{version}-Linux-arm64.AppImage` for your architecture
2. Add execute permission:

```bash
chmod +x ICodeEasy-v{version}-Linux-*.AppImage
```

3. Run:

```bash
./ICodeEasy-v{version}-Linux-*.AppImage
```

## Verify Installation

After installation, launch ICodeEasy:

1. The app window displays correctly
2. An ICodeEasy icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

## Version Updates

ICodeEasy does not include an auto-updater. Upgrades follow a "lightweight version check + manual download from the official site" flow:

- The "Settings > About" page automatically checks whether you are on the latest version and shows a notice when a new version is available
- Clicking the update check opens the official download page
- Download the latest installer and install it over the existing copy — your configuration data is not affected

## Uninstall

### Windows

- Uninstall via "Settings > Apps"
- Or run the uninstaller in the installation directory

### macOS

- Move `ICodeEasy.app` to Trash
- Optional: Delete the configuration directory `~/.icodeeasy/` (and the retained legacy `~/.cc-switch/` rollback copy, if present)

### Linux

```bash
# Debian/Ubuntu
sudo apt remove icodeeasy

# Fedora/RHEL
sudo dnf remove icodeeasy

# AppImage: simply delete the .AppImage file
```
